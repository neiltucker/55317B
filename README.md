# 55317B Querying Microsoft SQL Server 2025

**Courseware Access:** [Software Tutorial Services](https://www.softwaretutorialservices.com/course/55317b)  
* **Duration:** 3 Days (10 Modules)  
* **Audience Level:** Beginner  
* **Format:** Instructor-Led / Bootcamp  

---

## Course Overview

This three-day beginner course teaches students how to use Transact-SQL and other languages to query Microsoft SQL Server 2025. Using demonstrations and hands-on labs, students will master core querying skills, performance optimization, and semi-structured or vector data handling. This course serves as the foundation for all SQL Server-related disciplines including Database Administration, Database Development, and Business Intelligence.

> **AI Chat Assistant:** This course features an integrated, interactive **AI Tutor** available 24/7 directly within the courseware platform at no additional cost. Learners can ask questions in real time to explore Transact-SQL querying techniques, investigate semi-structured XML and JSON operations, examine data virtualization capabilities, and all other course topics.

---

## At Course Completion

After completing this instructor-led course, students will be able to:

* Query, sort and filter data in database tables
* Query external data sources
* Query SQL Server and Azure SQL Server programmatically
* Optimize query performance
* Modify data using Transact-SQL
* Work with XML and JSON formatted data
* Use stored procedures and functions
* Use SQL Server tools like SSMS and Visual Studio Code
* Use Data Virtualization
* Use PolyBase
* Use Azure Synapse Link
